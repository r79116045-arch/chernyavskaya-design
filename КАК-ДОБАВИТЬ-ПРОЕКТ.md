# Как добавить новый проект в портфолио (1 страница)

1. Создай папку `public/images/projects/imya-proekta-latinicey/`
   (латиницей, через дефис: `kvartira-lesnaya`).

2. Закинь фото/3D в эту папку. Порядок задаётся именем файла:
   `01.jpg`, `02.jpg`, `03.jpg`… Первое фото = обложка проекта.

3. Рядом положи файл `инфо.json`:
   ```json
   { "title": "Квартира на Лесной", "area": 96, "year": 2026,
     "city": "Тюмень", "desc": "Пара предложений о проекте.", "order": 4 }
   ```
   `order` — место в списке (1 = первым). Всё, кроме title, можно не указывать.

4. Запусти сайт (`pnpm dev` или `pnpm build`) — проект подхватится сам:
   карточка в сетке, своя страница, галерея из всех фото папки.

Убрать проект = удалить/переименовать папку. Больше ничего трогать не нужно.
